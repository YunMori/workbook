**2. [기초]** 원시 자료형과 참조 자료형의 비교로 옳은 것은?

① 원시 자료형은 변수에 주소가 저장되고, 참조 자료형은 값이 직접 저장된다.
② 원시 자료형은 값이 복사되고, 참조 자료형은 주소가 복사된다.
③ 원시 자료형은 가변, 참조 자료형은 불변이다.
④ `Array`와 `Function`은 원시 자료형에 속한다.

**10. [응용]** `<a @click.stop.prevent="onLink">`처럼 Event Modifiers를 연결해 사용할 때 주의해야 할 점은?

③ Modifiers는 `v-bind`에서만 사용할 수 있다.

**11. [기초]** SPA(Single Page Application)에 대한 설명으로 **옳지 않은** 것은?

① 하나의 HTML 파일로 시작한다.
② 상호작용 시 페이지 전체를 새로 로드하지 않고 필요한 부분만 갱신한다.
③ 사용자가 다른 페이지로 이동할 때마다 서버에서 새 HTML 파일을 받는다.
④ 대부분 CSR 방식을 사용한다.

**12. [기초]** Bundler와 Vite에 대한 설명으로 **옳지 않은** 것은?

① Vite는 Webpack이라는 Bundler를 내부적으로 사용한다.
② Bundler는 여러 모듈과 파일을 하나(혹은 여러 개)의 번들로 묶어 최적화한다.
③ Bundler가 하는 작업을 Bundling이라 한다.
④ Vite는 빌드 도구와 개발 서버를 제공하는 프론트엔드 개발 도구이다.

**13. [응용]** Composition API와 Option API에 대한 설명으로 옳은 것은?

① Option API는 Vue3에서의 권장 방식이다.
② Composition API는 `data`, `methods`, `mounted` 같은 객체로 로직을 정의한다.
③ Vue3에서는 Option API를 더 이상 지원하지 않는다.
④ Composition API는 `import`한 API 함수들을 사용해 로직을 정의하며 Vue3의 권장 방식이다.

**17. [기초]** `watch(source, (newValue, oldValue) => { ... })`에서 각 인자에 대한 설명으로 **옳지 않은** 것은?

① `source`는 watch가 감시하는 대상이다.
② 두 번째 인자는 `source`가 변경될 때 호출되는 콜백 함수이다.
③ `oldValue`는 필수 인자로 반드시 작성해야 한다.

**18. [응용]** `computed`와 `watch`의 사용 목적을 비교한 것으로 옳은 것은?

① computed는 side-effect 수행용, watch는 값 캐싱용
② computed와 watch 모두 의존(감시)하는 원본 데이터를 직접 변경한다.
③ watch는 반환 값을 템플릿에 바로 출력하기 위해 사용한다.
④ computed는 계산한 값을 캐싱해 재사용, watch는 데이터 변화에 따른 특정 작업(외부 API 연동 등) 수행

**19. [기초]** Local Storage의 특징으로 **옳지 않은** 것은?

① 브라우저 내에 key-value 쌍을 저장하는 웹 스토리지 객체이다.
② 쿠키처럼 네트워크 요청 시 서버로 자동 전송된다.
③ 페이지를 새로 고치거나 브라우저를 다시 실행해도 데이터가 유지된다.
④ 여러 탭이나 창 간에 데이터를 공유할 수 있다.

① 하드 코딩된 URL을 사용하지 않아도 되고, URL 입력 시 오타를 방지할 수 있다.
② 라우트 매칭 속도가 빨라진다.
③ 컴포넌트를 지연 로딩(Lazy Loading)할 수 있다.

**21. [기초]** AJAX와 XMLHttpRequest에 대한 설명으로 **옳지 않은** 것은?

① AJAX는 하나의 특정 기술이 아니라 비동기적 웹 애플리케이션 개발에 사용하는 기술들의 총칭이다.
② AJAX의 목적은 전체 페이지 재로드 없이 HTML 페이지 일부 DOM만 업데이트하는 것이다.
③ `XMLHttpRequest`는 이름 때문에 XML 형식의 데이터만 가져올 수 있다.
④ 요즘은 XML보다 가볍고 JavaScript의 일부라는 장점 때문에 JSON을 많이 사용한다.

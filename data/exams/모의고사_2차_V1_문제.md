**30. [응용]** 아래 코드가 `Hi → Bye → Work` 순으로 출력되는 과정을 **Call Stack, Web API, Task Queue, Event Loop** 네 요소를 모두 사용하여 단계별로 서술하시오. (4줄 이상)

```js
console.log('Hi')
setTimeout(function myFunc() { console.log('Work') }, 3000)
console.log('Bye')
```

먼저 1번째 줄에 있는 console.log('hi')가 call stack에 들어간다 이후 web api가 아니기 때문에 바로 실행되어 output인 hi가 출력이된다 이후 setTimeout이 call stack에 들어가게 되는데 setTimeOut은 webapi 이기 때문에 webapi로 넘어가서 3000ms 3초를 기다리는 작업을 수행한다. 그와 동시에 비어있는 call stack에 3번쩨 줄에 있는 console.log('bye')가 들어오고 바로 out put으로 bye를 출력한다 그리고 3초가 지난후 web api에 있던 setTimeout이 끝나고 task queue에 mtfunc를 넣는다 Event loop가 callstack 과 task queue를 지속적으로 감시하면서 callstck이 비어 있을때 task queue에 있는 작업을 가져오기 때문에 myfunc는 callstack로 가게 되고 myfunc를 호출하고 그 안에 있는 console.log('work')를 호출하고 work 가 출력된다 이후 빈 myfunc를 callstack에서 빼면서 이 루프가 끝나게 된다.

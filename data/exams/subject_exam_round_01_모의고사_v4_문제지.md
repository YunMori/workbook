# Vue 소개(Introduction of Vue) 모의고사 — Version 4

---

## 객관식

**1.** Frontend Development에 대한 설명으로 옳지 않은 것은?

① 웹사이트/웹 애플리케이션의 UI와 UX를 만들고 디자인하는 것이다
② HTML, CSS, JavaScript 등을 활용해 사용자가 직접 상호작용하는 부분을 개발한다
③ Client ↔ Frontend Framework ↔ Server 구조에서 Frontend Framework 계층에 해당한다
④ 서버에 저장된 데이터를 관리하는 데이터베이스 설계를 전담한다

---

**2.** Client-side framework가 필요해진 이유로 슬라이드에서 강조한 두 가지는?

① 웹에서 하는 일이 많아졌다 / 다루는 데이터가 많아졌다
② 서버 성능이 좋아졌다 / 네트워크 속도가 빨라졌다
③ 브라우저 종류가 줄었다 / 표준이 통일되었다
④ 모바일 기기가 사라졌다 / 데스크톱만 사용한다

---

**3.** SPA(Single Page Application)에 대한 설명으로 옳은 것은?

① 여러 개의 HTML 파일이 서버로부터 각각 로드된다
② 페이지 이동마다 전체 페이지가 새로 로드된다
③ 하나의 HTML 파일로 시작하여 필요한 부분만 동적으로 갱신한다
④ 항상 서버에서 완성된 HTML을 전달받아 렌더링한다

---

**4.** SPA가 주로 사용하는 렌더링 방식은?

① SSR(Server-side Rendering)
② CSR(Client-side Rendering)
③ MPA(Multi Page Application)
④ SSG(Static Site Generation)

---

**5.** CSR의 동작 과정을 순서대로 바르게 나열한 것은?

① 서버가 완성된 HTML 전달 → JS 파싱 → DOM 렌더링
② 브라우저가 최소 HTML + JS 응답을 받음 → 클라이언트에서 JS로 DOM 업데이트 → 이후 서버는 JSON 데이터만 응답
③ 클라이언트가 DB에 직접 접속 → HTML 생성 → 서버 전송
④ 서버가 매 요청마다 새 HTML 파일을 생성해 응답

---

**6.** CSR의 단점으로 옳은 것은?

① 빠른 페이지 전환
② 느린 초기 로드 속도와 SEO 문제
③ Frontend/Backend 분리가 불가능함
④ 새로고침 없는 UX 제공 불가

---

**7.** MPA(Multi Page Application)에 대한 설명으로 옳은 것은?

① 하나의 HTML 파일로 모든 화면을 구성한다
② 여러 HTML 파일이 서버로부터 각각 로드되며 페이지 이동마다 새 HTML을 로드한다
③ 클라이언트에서만 렌더링이 이루어진다
④ Vue, React 같은 프레임워크만 사용 가능하다

**14.** Vue 앱을 HTML 요소에 탑재(mount)하는 것에 대한 설명으로 옳은 것은?

① `mount()`는 여러 번 반복 호출해도 무방하다
② 각 앱 인스턴스에 대해 `mount()`는 한 번만 호출 가능하다
③ `mount()`는 setup 함수 내부에서만 호출할 수 있다
④ `mount()`는 CDN 방식에서는 사용할 수 없다

---

**15.** Vue 컴포넌트의 `setup` 함수에 대한 설명으로 옳지 않은 것은?

① 컴포넌트가 동작하기 전 미리 준비하는 시작점/초기 설정용 함수이다
② 데이터 정의, 화면 표시 값 계산 등의 로직을 준비할 수 있다
③ setup에서 준비한 값은 반드시 콘솔에만 출력해야 하며 템플릿에서 사용할 수 없다
④ setup에서 준비한 값들은 템플릿 등 다른 부분에서 바로 사용 가능하다

---

**16.** `ref()` 함수에 대한 설명으로 옳은 것은?

① 반응형 상태(데이터)를 선언하는 함수이며, `.value` 속성을 가진 객체로 값을 래핑해 반환한다
② DOM 엘리먼트를 직접 선택하는 함수이다
③ 이벤트 리스너를 등록하는 함수이다
④ 컴포넌트를 다른 컴포넌트에 등록하는 함수이다

---

**17.** 다음 중 JS 코드에서 `message.value`가 아니라 `message`만 출력했을 때 콘솔에 표시되는 것은? (`const message = ref('Hello vue!')`)

① 문자열 'Hello vue!'
② ref 객체
③ undefined
④ null

**18.** 템플릿에서 ref 값을 사용할 때의 특징으로 옳은 것은?

① 템플릿에서도 반드시 `.value`를 작성해야 한다
② 템플릿에서는 `.value`를 작성할 필요 없이 자동으로 unwrap된다
③ 템플릿에서는 ref를 아예 사용할 수 없다
④ 템플릿에서 ref 값은 항상 문자열로 강제 변환된다

---

**19.** `createApp()`에 전달되는 객체(Vue 컴포넌트)의 상태 선언 규칙으로 옳은 것은?

① 컴포넌트의 상태는 setup() 함수 내에서 선언되어야 하며, 객체를 반환해야 한다
② 컴포넌트의 상태는 반드시 전역 변수로 선언해야 한다
③ setup() 함수는 아무것도 반환하지 않아야 한다
④ 상태는 오직 mount() 이후에만 선언 가능하다

**25.** Single-File Component(SFC)에 대한 설명으로 옳은 것은?

② 컴포넌트의 템플릿, 로직 및 스타일을 하나의 `*.vue` 파일로 묶어낸 특수한 파일 형식이다
③ HTML만 작성할 수 있고 JS/CSS는 포함할 수 없다
④ Node.js에서만 실행 가능한 서버 전용 파일이다

**27.** `<template>`과 `<script setup>` 블록에 대한 설명으로 옳은 것은?

② 하나의 `*.vue` 파일에 최상위 `<template>` 블록과 `<script setup>` 블록은 각각 하나만 포함할 수 있다
③ `<script setup>`은 여러 개 작성해야 정상 동작한다

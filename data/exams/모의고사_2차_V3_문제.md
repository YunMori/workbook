**1. [기초]** 변수 선언 키워드의 스코프 연결로 옳은 것은?

① `var` — 블록 스코프 / `let` — 함수 스코프
② `var` — 함수 스코프 / `let`, `const` — 블록 스코프

**2. [기초]** `null`과 `undefined`에 대한 설명으로 옳은 것은?

① `null`은 변수 선언 후 값을 할당하지 않으면 자동으로 할당된다.
② `undefined`는 값이 없음을 의도적으로 표현할 때 개발자가 직접 할당한다.
③ `null`과 `undefined`는 조건문에서 항상 `true`로 평가된다.
④ `typeof null`이 `"object"`로 출력되는 것은 설계 당시의 버그를 하위 호환 때문에 유지한 결과이다.

**4. [기초]** DOM 조작 메서드에 대한 설명으로 **옳지 않은** 것은?

① `document.appendChild(tagName)` — 작성한 tagName의 HTML 요소를 생성하여 반환
② `Element.setAttribute(name, value)` — 속성이 이미 있으면 갱신, 없으면 새로 추가
③ `Element.removeAttribute()` — 지정된 이름을 가진 속성 제거
④ `element.textContent` — 요소의 텍스트 콘텐츠를 표현

**5. [응용]** 호이스팅(hoisting)에 대한 설명으로 옳은 것은?

① `let`, `const`로 선언한 변수는 선언 이전에 접근하면 `undefined`가 반환된다.
② `var`로 선언한 변수는 선언 시 `undefined`로 값이 초기화되는 과정이 동시에 발생한다.
③ `var`로 선언한 변수는 선언 이전에 접근하면 `ReferenceError`가 발생한다.
④ 함수 표현식은 호이스팅되므로 정의 전에 호출할 수 있다.

**13. [응용]** Vue Application instance에 대한 설명으로 **옳지 않은** 것은?

① 모든 Vue 애플리케이션은 `createApp` 함수로 새 Application instance를 생성하며 시작한다.
② 각 앱 인스턴스에 대해 `mount()`는 필요한 만큼 여러 번 호출할 수 있다.
③ `createApp` 함수에는 객체(컴포넌트)가 전달된다.
④ 모든 App에는 다른 컴포넌트를 하위로 포함할 수 있는 Root 컴포넌트가 필요하다.

**14. [기초]** Single Root Element에 대한 설명으로 가장 적절한 것은?

① Vue 3에서는 최상단 요소가 여러 개면 컴파일 오류가 발생한다.
② `<template>` 블록은 반드시 `<div>`로 시작해야 한다.
③ Root 요소가 하나여야 `v-for`를 사용할 수 있다.
④ 가독성, 스타일링, 컴포넌트 관리를 위해 각 컴포넌트에 최상단 HTML 요소를 작성하는 것이 권장된다.

**15. [응용]** Props의 특징으로 **옳지 않은** 것은?

① 자식에서 props를 수정하면 부모의 원본 데이터도 함께 변경된다.
② 부모 속성이 업데이트되면 자식으로 전달된다.
③ 자식 컴포넌트 내부에서 props를 변경하려고 시도해서는 안 되며 불가능하다.
④ 부모 컴포넌트가 업데이트될 때마다 이를 사용하는 자식의 모든 props가 최신 값으로 업데이트된다.

**17. [기초]** Virtual DOM의 장점으로 강의자료가 제시한 것이 **아닌** 것은?

① 효율성 — 실제 DOM 조작을 최소화하고 변경된 부분만 업데이트
② 보안성 — XSS 공격을 원천 차단
③ 반응성 — 데이터 변경을 감지하고 Virtual DOM을 갱신하여 UI 자동 업데이트
④ 추상화 — 개발자가 실제 DOM 조작을 Vue에게 맡길 수 있음

**20. [응용]** Dynamic Route Matching에 대한 설명으로 **옳지 않은** 것은?

① 매개변수는 경로에서 콜론(`:`)으로 표기한다. (예: `/user/:id`)
② `RouterLink`에서 매개변수는 객체의 `params` 속성으로 전달한다.
③ `params` 객체의 key 이름은 라우터에 지정한 매개변수 이름과 달라도 무방하다.
④ 컴포넌트에서 `$route.params`로 매개변수를 참조할 수 있다.

**21. [기초]** 브라우저 환경의 비동기 처리 요소에 대한 설명으로 **옳지 않은** 것은?

① Task Queue는 LIFO 구조로, 가장 나중에 들어온 작업을 먼저 Call Stack으로 보낸다.
② Call Stack은 LIFO 구조로 요청이 들어올 때마다 순차적으로 처리한다.
③ Web API는 JavaScript 엔진이 아닌 브라우저에서 제공하는 runtime 환경이다.
④ Event Loop는 Call Stack이 비어 있으면 Task Queue에서 가장 오래된 작업을 Call Stack으로 push한다.
